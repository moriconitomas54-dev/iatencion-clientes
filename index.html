Importar stock desde Excel

Archivos .xlsx, .xls o .csv · Máximo 5 MB y 5.000 filas. Primera fila: Código, Producto, Stock, Precio, Ubicación (opcional). Cada código debe ser único.

Los archivos se procesan en este navegador. Usá números de Excel o precios de texto como 140000,50 o 140.000,50.

Se reemplazará el catálogo completo de este rubro. Exportá el stock actual si querés conservar una copia.
